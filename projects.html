Credit Risk Scoring ML System

A complete machine learning system that predicts loan default risk and classifies borrowers into risk tiers. I built the entire pipeline from data preprocessing through cloud deployment, achieving 87% F1 score and 92% ROC-AUC using XGBoost. The system includes transparent AI with SHAP explainability and an interactive dashboard.

Key Features

  • Achieved 87% F1 Score and 92% ROC-AUC with XGBoost, providing reliable predictions for loan default risk
  • Deployed to Streamlit Cloud with automated CI/CD pipeline directly from GitHub
  • Integrated SHAP explainability to make AI decisions transparent and interpretable for regulatory compliance
  • Built comprehensive ETL pipeline with feature engineering that creates over 20 predictive features from raw loan data
  • Trained and compared three different models with hyperparameter tuning to find the best performer
  • Created an interactive dashboard for real-time risk assessment with visual explanations
